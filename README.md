# Планировщик задач

Небольшой веб-планировщик задач с фронтендом, REST API и SQLite.
Приложение позволяет добавлять, редактировать, удалять, выполнять задачи, работать с правилами повторения и искать задачи.

## Выполненные задания со звёздочкой

1. Расширенные правила повторения задач (`w`, `m`, поддержка списков и спец-значений дней месяца).
2. Поиск в `GET /api/tasks` по подстроке и по дате в формате `dd.mm.yyyy`.
3. Аутентификация через `TODO_PASSWORD` и cookie `token` для API:
   - `/api/task` (все методы),
   - `/api/tasks`,
   - `/api/task/done`.
4. Docker-сборка и запуск приложения.

## Локальный запуск

1. Установить Go (версия из `go.mod`).
2. В корне проекта выполнить:

```bash
go run .
```

По умолчанию сервер поднимется на `http://localhost:7540`.

### Полезные переменные окружения

- `TODO_PORT` - порт сервера (по умолчанию `7540`).
- `TODO_DBFILE` - путь к SQLite-файлу (по умолчанию `scheduler.db`).
- `TODO_PASSWORD` - пароль для включения аутентификации (если пустой, аутентификация отключена).

Пример:

```bash
TODO_PORT=7540 TODO_DBFILE=scheduler.db TODO_PASSWORD=12345 go run .
```

## Запуск тестов

1. Убедиться, что сервер запущен на порту из `tests/settings.go` (`Port`).
2. Проверить путь к БД в `tests/settings.go` (`DBFile`).
3. Запустить:

```bash
go test ./tests
```

Для проверки авторизации:
1. Запустить сервер с `TODO_PASSWORD`.
2. Получить токен через `POST /api/signin`.
3. Подставить токен в `tests/settings.go` в переменную `Token`.
4. Запустить `go test ./tests`.

## Docker

Сборка образа (бинарник собирается внутри контейнера):

```bash
docker build -t scheduler:latest .
```

Запуск контейнера:

```bash
docker run --rm -p 7540:7540 \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE=/data/scheduler.db \
  -e TODO_PASSWORD=12345 \
  -v "$(pwd)/data:/data" \
  scheduler:latest
```

После запуска приложение доступно по адресу `http://localhost:7540`.
